# SolidWorks 装配体显示工具通用版

## 兼容范围

- SOLIDWORKS 2017 及以后版本
- 64 位 Windows / 64 位 SOLIDWORKS
- .NET Framework 4.x

安装包不携带预编译的“通用 DLL”。安装时会读取本机 SolidWorks `api\redist` 里的官方 Interop，编译出与本机版本匹配的插件。

## 安装

1. 完整解压本安装包。
2. 保存工作并退出所有 SolidWorks 进程。
3. 双击 `Install.cmd`，允许管理员权限。默认选择本机安装的最高 SolidWorks 版本。
4. 启动 SolidWorks，在“工具 > 插件”中确认“SolidWorks 装配体显示工具”已勾选。
5. 打开装配体，在“装配体显示”选项卡中使用两个按钮。

安装程序会把编译后的插件和匹配的 Interop 放到 `%ProgramData%\SolidWorksVisibilityTools`。安装成功后可以移动或删除原安装包。

如果同一台电脑安装了多个 SolidWorks 版本，可以在 PowerShell 中指定目标：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -SolidWorksInstallDir "D:\Program Files\SOLIDWORKS Corp\SOLIDWORKS"
```

同一时间只能注册一个目标版本；重新指定安装会替换之前的注册。

## 功能边界

- “显示所有隐藏零部件”只恢复隐藏组件，不解除压缩组件。
- “恢复全部不透明”处理当前装配体配置中的组件级透明度，并保留组件颜色；不清除零件内部的面级、实体级或玻璃材质透明度。
